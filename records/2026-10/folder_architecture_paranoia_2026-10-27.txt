3. /free-for-all-debate — 5 problems, 4 competitors, 2 picks each
 P1 Prompts live inside code (49 copies-in-strings, duplicates).
 P2 Oracle doesn't have a per-realm brief to read.
 P3 Dev-side folders for Claude Code (domain folders with prompts/tools/data).
 P4 Realms/phyla as visible "folders" in the app.
 P5 Engelbart/Unix as the design principle.
 A "Unix purist" (P1, P3): prompts become plain text files in /prompts, one per job, read by app, api and Python
   alike (realm_lenses.json proves it works). Kills 8 duplicate tutor prompts (rule 8), makes every prompt reviewable
   and diffable, and gives CC a real prompts/ folder per domain.
 B "Alex's daily use" (P2, P4): Alex never sees the repo; what he feels is Oracle not knowing his realm state and
   clutter. A realm folder = the realm home he got today + a generated "realm brief" Oracle reads when a message is
   about that realm (rank, target, open tasks, last 5 wins). That's the folder he'll actually use.
 C "Why-not / 48h" (P1, P3): moving 49 prompts is a big refactor with no new beat or post; runtime fetch of prompt
   files adds a request per call unless bundled; moving docs breaks links (rule: renames need full-repo greps).
   Against A: do it only for prompts that are duplicated or shared across app/Python, not all 49.
 D "Engelbart reader" (P5, P4): the paper's core is H-LAM/T (Human using Language, Artifacts, Methodology, Training)
   bootstrapping - tools that improve the tools. RPGACE's loop (share -> analyse -> tasks -> do -> XP -> review) IS
   that. Write it down once as the design principle (DESIGN.md + Oracle's CORE line) and use it as a test for new
   builds: "does this augment Alex's thinking or just store things?" Plus actually read it (Engelbart Hour task).
 A vs C on P1: merged - a prompts/ folder, but migrate only (a) duplicated prompts, (b) prompts shared between app and
   Python/api, (c) the big Oracle system prompts; leave one-off small prompts in place. Bundle into the min build (no
   runtime fetch) via scripts/minify_client.js, Python reads the files directly.
 B vs D on P4: merged - realm home is the realm folder; adding Prompts ("Ask Oracle as Chef") and Data (library/ideas
   for that realm's phyla) sections is small and on the screen he already has.
 P3: A vs C unresolved -> question for Alex (low value if he never opens the repo; CC benefits).
