1) Claude plan usage: YES, measurably. ~65-70K fewer tokens at every session start and in
   every turn's context; ~2.5K fewer per turn from skill descriptions; skills cost ~1/3 when
   invoked. Fewer compactions in long sessions. Caveat: a topic file read adds 0.5-2K back.
2) Domain context picking for /CEO: PARTLY. The split exists but by "area", not by the 8
   domains, and /CEO doesn't use it yet. Fix is small: one topic file per domain + a CEO
   Loop 1 rule "read CLAUDE.md + docs/claude/<domain>.md + landmines only".
3) Galaxy Map: NO direct change. Only its rules file got cheaper to read. The externals ->
   domains + dimension dissolve step below is what makes the map simpler.
4) Claude API in the app: NO change — the app never reads these files. The real lever is
   SELF_KNOWLEDGE (99K chars). Same fix shape as CLAUDE.md: section it by domain (the
   Professor already picks sections), trim story, stop the full dump on the 7 forced paths,
   add a size gate to the existing checks.
