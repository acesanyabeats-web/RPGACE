5. /free-for-all-debate (4 competitors, each took 2 problems)
A Minimalist (size, read cost): 25KB core, all else on demand. Strong on cost;
  weak — rules end up off-screen.
B Safety-first (missed rules, landmines): keep every rule and landmine whole in
  core, move only domain facts. Strong on safety; core stays ~70KB.
C Generate it (stale numbers, drift): replace "Live numbers" with the queries that
  produce them; facts that change weekly shouldn't be hand-typed. Strong — numbers
  in prose go stale within days (proven: 4 stale counts in this file).
D Skills as home (duplication, source of truth): framework detail already lives in
  skill files; flip "CLAUDE.md wins" so the skill file is the source, CLAUDE.md a
  one-liner. Strong dedup; needs every "CLAUDE.md wins" line updated.
Council of 5 verdict: hybrid. Rules as short imperatives stay in core (B, trimmed
to the rule, story out — A). Live numbers become a query list (C). Framework detail
moves to skill files with the source of truth flipped (D). Domain facts go to topic
files (Alex's choice). Expected core: ~30-45KB.
Why NOT do it: a big rewrite of the file every session trusts could lose a landmine
that saved real data. That is why CD-0 comes first and every item is checked.
