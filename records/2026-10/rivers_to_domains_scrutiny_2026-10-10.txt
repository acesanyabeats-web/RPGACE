== /free-for-all-debate (4 competitors, each takes 2 problems) ==
A — "Simplicity"
  P1 Single-module domains (Bookworm, Cooking, Wishlist): keep them. A domain is a thing Alex uses, not a size bucket. They match the consumer map 1:1, and they'll grow (HABITS already plans more).
  P2 "Platform" as a real domain, not a hidden exclusion list. Honest, and it ends the "cross-cutting exclusions" special case that hides 10 modules.
B — "Power / optimal"
  P3 Put the domain INSIDE the app: each RPGACE.register('x', { domain: 'cooking', … }). The Galaxy scripts read it by regex, so there is ONE source of truth and RIVER_MODULES (and its drift bug class) is deleted.
  P4 Use domains at runtime:
    • Oracle grounding loads only the SELF_KNOWLEDGE section for the domain being asked about (fewer tokens per call).
    • errorLog/smoke tally per domain ("Cooking: 3 errors, 2/9 hand-ticked").
    • Oracle can list a domain's real modules live from the registry instead of a hand-written string that goes stale.
  This is the "more powerful/optimal" half; the relabel alone wouldn't deliver it.
C — "Sceptic"
  P5 Cost/risk: ~2,300 script mentions + 23 pages. A blind sed rename WILL break generators (anchors, page names, idempotency checks). Counter-proposal: build DOMAIN data alongside, switch each generator, regenerate and verify, THEN remove river code. Never one big rename.
  P6 Don't lose real evidence: RIVER_FLOWS holds ~40 evidence-commented cross-river edges (11 added Sep 16 from real cross_refs). These must be RE-DERIVED at domain level from the module-level evidence, not deleted with the river table.
D — "Placement disputes"
  P7 Content Intelligence (intel*, ciAutoPropose, researchTabs): put it in Knowledge Tree, not Content. It turns videos INTO encyclopedia/taxonomy insights; its output lands in the tree. (Counter: it lives under the Content Pipeline UI today.) → open fork for Alex.
  P8 Platform caption panels (insta/youtube/tiktok Oracle panels): put them in Content, not Oracle. They exist to make posts. (Counter: they are Oracle command panels.) → open fork for Alex.
