6. COUNCIL OF 5
=====================================================================
Risk: auto-shelving wrong phylum -> editable chip; keyword prefilter (existing phylum keyword lists)
  first, cheap Oracle call only when no keyword match (rule 11). Private data -> table locked like
  people/plans (service-role read via /api/data-write action read).
Cost: shelving mostly free (keywords); web lookups = 1 Gemini call + 1 follow-up Oracle call, only
  when Oracle decides it needs the web and the library had nothing.
Maintainability: ONE new table library_items with a kind column (not a table per kind); URL-normalised
  dedup (same link saved twice = one item); feeds hook existing save points (no new pipelines);
  reuse askMyData trailer flow, recall resurfacing, people list, secureWrite.
UX: phone-first page; quick-add sheet (link / note / quote / recommendation); filters shelf/topic/
  kind/date + search; star button on Oracle replies.
Why NOT: more surface while hand-testing is behind. Mitigation: start fresh = no migration risk; the
  library is passive (no review queue).
/simplify: no separate web_lookups table (kind='web_lookup'); no second bibliography; Chronicles
  subsections read existing tables (content_productions, planned_cooks/recipes, plans) - no copies.

7. DRAFT PLAN — "Life Library" (LL-1..LL-6)
=====================================================================
LL-1 Library core: private table library_items (kind book/video/link/web_lookup/screenshot/answer/
     music/file/course/recommendation/note/quote; title, url, url_key unique, summary, topics[],
     phylum_number, source_table/source_id, recommended_by -> people, status to_check/done,
     created_at). "📚 Life Library" page under Knowledge: shelf/topic/kind/date filters, search,
     quick add, shelf chip edit, 2-tap delete. Auto-shelve: keywords first, Oracle (cheap) fallback.
LL-2 Feeds (new items only): Bookworm books, Content Intelligence reports, screenshot inbox, File
     Analyzer / Video Finder, new reference tracks, ⭐ on Oracle replies, recommendations (People
     picker). Encyclopedia idea cards show a link to their source item.
LL-3 Oracle web lookups: WEB_QUERY trailer (askMyData pattern) - library searched first, Gemini only
     for what's missing; result saved as kind web_lookup with date/topic/answer/links; "🌐 Searched"
     + links under the reply; "🔗 Find links" button on Jargon terms and Bookworm insights.
LL-4 Resurface: Recall adds 1 library item a day to the Morning Brief (unread recommendations and
     older items first).
LL-5 Tree hook: Phylum Path shows each phylum's shelf (library item count + list); when a phylum is
     rebuilt, its shelf is the source material. Bibliography view points to the Life Library.
LL-6 Chronicles subsections: Beats & content, Recipes cooked, Trips & plans done (read from existing
     tables, no copies).
