REAL BUILD
===========================================================================
scripts/check_self_knowledge_staleness.py -- a real, regex-only, no-AI-cost
script, same family as verify_anchors.py and the Galaxy Map headline-fact
checks:
  1. extract_self_knowledge() -- one shared extraction function (rule 8),
     the same non-greedy DOTALL pattern the Sep 23 rewrite script used.
  2. last_mentioned_date() -- real full "Mon DD YYYY" mentions only (a
     bare "Sep 2026" with no day, or "Sep 22" with no year, is
     deliberately not counted -- too ambiguous to trust). Returns the
     MAX real date found, or None (a real, honest failure mode -- flagged
     as maximally stale, never silently treated as fresh).
  3. count_ships_since() -- parses real patch_notes.html card-title date
     prefixes ("Mon DD --", this project's own real, confirmed
     convention, no year in the card itself), with a cross-year-boundary
     guard so a Jan card doesn't get silently misdated once the project
     timeline actually crosses a year boundary.
  4. STALE if (days_stale > 7) OR (ships_since >= 3) -- an OR, matching
     Q1's real confirmed answer (either signal alone is enough to flag).

Never auto-rewrites SELF_KNOWLEDGE -- deliberately report-only. Rewriting
it is a real semantic-judgment task (what's actually true, what's
resolved, what's still open), the same discipline the Sep 23 2026 fix
itself used -- automating that would risk exactly the kind of confidently
wrong content this whole audit was triggered by in the first place.
