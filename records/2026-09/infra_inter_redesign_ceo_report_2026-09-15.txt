=== A REAL BUG CAUGHT MID-BUILD, NOT SHIPPED BLIND ===

The plan and this build's own first pass used a hyphenated anchor form
(`#unit-orchestrator-cc`) throughout planning prose. The actual code
generates `id="unit-{unit_id}"` where `unit_id` is the real Python
dict key (`orchestrator_cc`, underscore) — so the real generated anchor
is `#unit-orchestrator_cc` (underscore), not the hyphenated form the
plan assumed. Caught by an explicit post-build content verification step
(grepping the actual generated HTML for the literal id, not just
checking the build succeeded) rather than assumed correct from a clean
build — the first regeneration produced a page with the right structure
but a real, silently broken link (`galaxy_map.html` linking to an id
that didn't exist on the target page). Fixed by aligning every
cross-file reference to the real underscore form, then a full pipeline
re-run confirmed the fix.
