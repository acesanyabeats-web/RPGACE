===========================================================================
Real tooling built (both idempotent + reusable, rule 8 — not one-off
scripts)
===========================================================================
scripts/patch_notes_add_anchors.py:
  Deterministic id scheme: card-YYYY-MM-DD-<slug> (slug = first ~6
  significant words of the title, emoji/punctuation stripped, stopwords
  dropped, kebab-case). Collisions (several cards share a date -- 15+ on
  Sep 17 alone) resolved with a numeric suffix, stable given fixed file
  order. Idempotent: skips any card that already carries a real id, so a
  future batch (Aug/Jul/roadmap) can be run without disturbing this
  batch's work.

scripts/dd1_collapse_bullets.py:
  Takes a batch module defining (find_substr, new_oneliner) pairs. Finds
  each CLAUDE.md bullet by a short, unique substring (never the whole
  multi-KB bullet text -- avoids transcription risk) -- FAILS LOUD if a
  substring matches 0 or 2+ lines, refusing to touch anything until every
  bullet in the batch is unambiguous. Appends the full original bullet,
  verbatim, into CLAUDE_archive.md under a new dated header. Replaces the
  CLAUDE.md line with the batch's real durable one-liner + a real
  markdown link into the matching patch_notes.html anchor.
