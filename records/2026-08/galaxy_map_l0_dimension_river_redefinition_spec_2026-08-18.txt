    - This directly reuses/repurposes existing Galaxy Map primitives
      already built this multi-day effort: the Alex-bubble (evidence-gated,

      yes/no fork pages, Dimensions Matrix/G30 (multi-home per-module tags).

      new TOP-LEVEL organizing structure (L0 units -> their edges) that
      those primitives get surfaced through.

    and bundle"

      "so both interactive and non-interactive processes can be

      not two unrelated concepts; a dimension can be read as a "far shore"

    - "some rivers will become dimensions and merge where needed to make
      sense" (from the original trigger prompt) — i.e. this is NOT purely
      additive; some of the current 16 rivers may need to be reclassified
      as dimensions instead, or merged with each other, once the new
      module-interaction-based grouping is actually computed from real
      evidence. Real, open, needs real data before deciding which (if any)
      rivers actually merge/convert — not to be guessed blind.
