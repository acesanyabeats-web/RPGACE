=== LOCKED ARCHITECTURE (verbatim rule, now confirmed) ===

- INFRA = one L0 unit's own bubble system (its own real
  river -> module -> [function] migration drill-down over ITS OWN
  evidence). Not a new rendering concept — this already exists for 4
  units (Supabase/External AI/Oversight Docs/Orchestrator CC), and real
  candidate data already exists, unwired, for 3 more (see below).

- INTER = a real composition: when 2+ units' own Infra systems both
  land on the SAME river or SAME module, producing one combined,
  evidence-backed relationship (never invented for symmetry).

- RIVER pages get INFRA ONLY: one bubble per real unit whose Infra
  system touches that river, each linking straight into that unit's own
  drilldown filtered to this river. No Inter bubble at river grain,
  ever.

- MODULE pages get INFRA and/or INTER, whichever real evidence
  supports: a direct single-unit Infra bubble where exactly one unit's
  evidence lands on that specific module; an Inter bubble where 2+
  units' evidence converges on that same specific module; both,
  neither, or one, strictly following the real data.

- Every river/module page shows this alongside its EXISTING flow
  arrows (river-to-river RIVER_FLOWS, module-to-module cross-calls) —
  additive, never replacing the existing structural-flow rendering.

- Real, standing assumption (stated, not yet re-confirmed a second
  time — Alex did not object when this was restated): all of this is
  evidence-gated. A unit with no real river/module-shaped evidence
  produces zero Infra/Inter bubbles anywhere, rather than something
  being fabricated to make every unit/river/module look symmetric.
