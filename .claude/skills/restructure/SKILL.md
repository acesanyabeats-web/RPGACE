# /restructure — would this repo change the skeleton, and should it?

Alex, July 29, verbatim: *"use this as one side of debate. the other side debates why using this instead of whole pieces of infrastructure in rpgace and claude code joint system could make 1) code shorter 2) loads quicker 3) output more detailed, context appropriate and meticulously picked. use /Engineer as a way to envision implementation for arguments, /scope and /godmode for research, /5thDimension and /omnitrix without fable with opus 5 and /aintergration. this is then council of 5 on output of debate with /scope and handed full report on rebirth of rpgace... the purpose is to see how fitting a repo would change the skeleton of rpgace-claude code system to make it evolve."*

Aintergration usually, and rightly, rejects whole third-party repos as a different stack. This asks something rarer: does the repo point at a real weak spot in our own skeleton, even if none of its code ever ships?

## Steps
1. **Side A** — Aintergration's verdict (reuse it if already run): keep existing infrastructure; adopt only what survives on its own.
2. **Side B** — a case on three axes only: a *specific* piece of the repo replacing a *specific* piece of ours makes (1) code shorter, (2) load/response quicker, (3) output more detailed and better picked. GODMODE + `/scope` supply real baselines (sizes, latency/cost, the current retrieval mechanism) for both sides.
3. **Sketch, don't build** — use `/Engineer` Stages 1-2 for each surviving claim: files touched, new tables, a funnel tier. A claim that can't be sketched is dropped.
4. **Reconcile** through `/5thDimension` Phases 3-4 (no Fable; Opus sketches, the session reviews). Re-run Aintergration only for a new third-party candidate.
5. **Council of 5 report from the transcript**, grouped `/scope`-style: forks for Alex, rejects with reasons, confirmations.
6. **"Rebirth of RPGACE" report** — per surviving claim: what changes in the skeleton, its tier, and what evidence is needed before building. A report only; Tier 3 needs Alex.

## Guardrails
- Side B must be real; "nothing to replace" is a valid result.
- Not for "should I add one tool".
- Nothing is built from this skill; each surviving finding gets its own spec and `/Engineer` run.
