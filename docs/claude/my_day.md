[Day Bookends](../../patch_notes.html#card-2026-10-27-day-bookends)
- Focus timer (MD-4): `logic.startFocus`/`focusPhases`, focus rows in `myday_alarms`, +15 bonus XP. [story](../../patch_notes.html#card-2026-10-20-focus-timer)
- Good morning (MD-5): `ui.openMorning` (+ `dashDeck.ui._fillBrief`), opened by ☀️ I'm up (`ui.imUp`) or the Morning Brief button — never by the clock. `_fillBrief` calls `morningBrief.ui._showSaved` so a reopen always shows today's saved brief (or writes it after 07:00 if none is saved). Today's realm picks and each Top 3 line carry ＋ Add to today (`ui.addTodayBtn` → `logic.placeNext`, next free 30 min, realm block). [story](../../patch_notes.html#card-2026-10-20-good-morning) Since MB-3 (Oct 28) it is one scroll of 5 numbered chapters (Wake, Start here, Today's quest, Make, Catch up): `ui.storyCss` places every piece (incl. the strips other modules add to `#mb-wrap`, and the brief's section cards from `morningBrief.logic.sections`) by CSS order, one card style, scroll-in motion (off with reduced motion).
- Evening review (MD-6): `ui.openEvening(opts)` — from 🌙 Going to bed (`opts.bed`: Skip review / Save & next → `ui.openGoodnight`) or as yesterday's catch-up on I'm up (`opts.catchUp`); Tomorrow/Drop/Skip; `journal` row `evening_review` → +10 Mind. [story](../../patch_notes.html#card-2026-10-20-evening-review)

Awake = up within 20h, no bed press (`logic.awake`). `missedItems` counts Morning only on a day started with I'm up. [story](../../patch_notes.html#card-2026-10-27-day-bookends)
- Schedule links (MD-7): 🌅/🌙 + ☀️ My Day links (`logic.calendarBookends`, `ui.openFromSchedule`); 🧹 Homekeeper block (was Housekeeping/"chore block"; `kind` stays `chores`, `realm` homekeeper since DL-6) via Plan my day + `ui.pickChores`. ## Doing Now (`doingNow`) — the store under ▶ Live now
- DL-2 (Oct 28): every Doing Now button opens ▶ Live now (`doingNow.ui.openStart`/`openJustDid` redirect; typed path `openTyped`/`openTypedDid`, used by Live now's Something else…); labels read "Live now". The rest of this section is the store and its pages. Live now behaviour: `docs/claude/realm_tasks.md`. [story](../../patch_notes.html#card-2026-10-28-day-log)
- Rows in `rpgace_agendas` with `source_type='doing_now'` + `realms`/`details`. 4h cap; repeats → offer a routine; XP via trigger `xp_on_doing_now` (30 XP split across realms, max 3 a day, skips planned_cook/gym links). Chronicles by realm + Sunday review. [DN](../../patch_notes.html#card-2026-10-16-doing-now) [cook/gym](../../patch_notes.html#card-2026-10-16-doing-now-cook-gym) [Chronicles](../../patch_notes.html#card-2026-10-16-doing-now-chronicles)
- AC-3: Doing now / I just did ask when + how long (`ui._askWhen`); live pages open for cook, gym, study (`studyHub`), reading (Bookworm in-progress book); Actions ticked with 0 XP so XP is never paid twice. [story](../../patch_notes.html#card-2026-10-22-when-and-live)
- Phone alarm (PA-1..5, Oct 28): `alarmSounds` (door: 🔔 in the 🌅 Morning block editor) lists `alarm_sounds` (public bucket `alarm_sounds`; link → `queued` → laptop `local_server.py` `import_alarm_sound` yt-dlp + ffmpeg 60 s mp3 → `ready`); edge fn `alarm-feed` (`q=status` RING/WAIT for due `wake`/`test:*` alarms with `phone_rang_at` null, picks a random sound into `myday_alarms.sound_url`, stamps `myday_settings.phone_last_seen`; `q=sound` 302; `q=stop`). MacroDroid steps: `alarmSounds.logic.SETUP`. Shares titled alarm/ringtone/wake up ask alarm-or-lesson (`shareInbox.ui.askAlarm`). [story](../../patch_notes.html#card-2026-10-28-phone-alarms)
- Wake Flow (WF, Oct 29 2026): the in-app alarm is a full-screen cover (`ui._alarmCheck`, `#myday-alarm`) with one big ☀️ I'm up (`#myday-alarm-done` → `ui.imUp`: alarm row done, so the phone feed answers WAIT; then Good morning). The 20s tick also loads alarm rows (`logic.syncAlarms`, 10-min throttle), so a cold open shows the cover. Left menu ⚡ Actions (`#ln-actions`, built in `leftNav._buildDrawer`) opens `ui.openActions`: I'm up/Going to bed, Morning Brief, Doing now, I just did, Evening review. [story](../../patch_notes.html#card-2026-10-29-wake-flow)
- WF-5 (Oct 29 2026): `alarm-feed` (source now in `supabase/functions/alarm-feed/index.ts`) answers SOON when a wake/test alarm is due within 150 s; MacroDroid's second If (SOON → Screen On + Launch RPGACE) loads RPGACE early (a dark locked screen does not load it). `ui._alarmCheck` shows the cover from 150 s before the alarm (silent until due) and also for test rings (`logic.syncAlarms` loads `kind=wake` + `test:*`), where the button is ■ Stop test ring (marks only that row done, never starts the day). A `rpgace:login` hook runs the check straight after sign-in. [story](../../patch_notes.html#card-2026-10-29-wake-flow-2)
- Bedtime and wake asks (Oct 29 2026): `push_bookends()` (called by `push_digest()` after `push_alarm`, run each minute by pg_cron `myday-push`) sends "🌙 Going to bed now?" once at 23:00 unless Going to bed was pressed in the last 12 h, and "☀️ Are you up?" once at 07:00 only when today has no `myday_alarms` wake row and the day wasn't started; both `sticky` (sw.js `requireInteraction`). Taps open `?open=bed` → `ui.goingToBed`, `?open=up` → `ui.imUp`. [story](../../patch_notes.html#card-2026-10-29-bed-up-asks)
- Good night closes the app (Oct 29 2026): after `logic.endDay` saves (review already in journal), `ui._closeForNight` tries `window.close()` and otherwise reloads to `?slept=1`, so the morning always runs fresh code. `RPGACE._noNightClose` turns it off (tests). [story](../../patch_notes.html#card-2026-10-29-bed-up-asks)
- Push priority (Oct 29 2026): `myday-push` sends with `urgency: high` (source in `supabase/functions/myday-push/index.ts`, deployed v2); sw.js shows every RPGACE alert with renotify/vibrate, never silent. Ranking against other apps is the phone's per-app setting.
- Night tasks (Oct 29 2026): routine "💧 Fill a cup of water for your bedside" (daily, evening). Night tasks show only in the 🌙 Night card (`logic.eveningModel` leaves them out of Not done); on 🌙 Going to bed, Save & next refuses until they're ticked. Good night is two steps: 📋 Plan tomorrow (or Skip) → then the alarm, and the app closes only after the alarm choice. [story](../../patch_notes.html#card-2026-10-29-bed-up-asks)
- One task card (Oct 29 2026): `ui.row` is the only task renderer: evening review Not done (routines, one-offs), Night/Morning cards, Good morning, My Day. Every row has a big ✓ Done next to the circle; a tick redraws the row in place (also inside pop-ups, which previously never updated: the circle bug) and fires `myday:ticked`; a tick on a past day's card is logged for that day.
- Block page (TK-2/3/4, Oct 29 2026): tapping a planned block on the timeline (`ui._tapSeg`) opens ▶ Live now for that block (`realmTasks.ui.openLive({block, date, seg})`): its steps (`logic.blockSteps` = Homekeeper routines + items) as `kit.taskCard`s via `ui.blockSteps`, + Add a step (`ui.addStepPicker`: your Actions and realm tasks, or free text → `logic.addToBlock`), ⋯ Move / edit (the old `ui.blockSheet`). Mode by time (`logic.blockMode`): now/past tick (past = fill in), future = plan (✕ Remove). Every step ticked → `logic.syncBlockFinish` writes `quest_log` `block_done:<id>` +15 XP once (same key as the focus timer, so never twice); an untick deletes it. A running block's Live now shows the same steps.
- Free gap that starts now (today): tapping it opens `ui.gapChoice` → ▶ Doing it now (`doingNow.ui.openStart` → Live now) or 📋 Plan a block (`ui.addInGap`); later gaps go straight to `addInGap` ([story](../../patch_notes.html#card-2026-10-29-gap-choice-xp-date)).
- Log what you did (TK-7, Oct 29 2026): empty past time on the timeline shows ✍️ log what you did (`ui._lane` past gaps); it and the evening review's ✍️ Log something you did open `ui.logPast` (times, realm, tick that realm's tasks or type your own) → `logic.logPastBlock` saves a realm block (method none), ticks every step (`setBlockItem` dates past-day steps at the block's start) and finishes it once, then opens its block page. Planning stays optional.
- Memory details (Oct 29 2026): every kept memory has ✏️ Edit (`eventMemories.ui.openEdit`: title, people, place, reflection/impression note, photo → `logic.update`). A past block's page has 🎞 Add details (`eventMemories.logic.forBlock`: one memory per block, `source 'block'`, found by date + start + realm, no extra XP since the block already paid).
- Live now list (TK-6, Oct 29 2026): the realm task list on ▶ Live now uses `kit.taskCard` (tick / ✓ Done straight away via doneInBlock/freeDone, or ▶ Start). With TK-1..6 the shared card is the only tick UI in My Day.
- Known gap: `xp_events.earned_on` is stamped the day a row is saved, not its `completed_at`, so XP for something logged after the fact lands on the logging day (the two Oct 27/28 meetups were moved by hand).
