## My Day (`myDay`, replaced the Quest Board)
- Home (MD-0): 5-step strip, `AREAS.myday`. [story](../../patch_notes.html#card-2026-10-18-my-day-home)

- Plan week (MD-2): `ui.weekTimeline`, drag via `logic.dragLimits`, methods per realm/block. [story](../../patch_notes.html#card-2026-10-20-plan-week-timeline)
- Plan my day (`ui.openPlan`): blocks only — the day's `chore_blocks` (from Plan week or + Realm/Housekeeping/Cooking/Shopping block added there, saved by Lock in), each filled via 📋 `ui.planBlock` (`logic.rankOptions`, due Actions by realm); no loose due list (`logic.buildDay` removed Oct 27 2026); frog / 1-3-5 kept. `opts.after` runs on close. [Day Bookends](../../patch_notes.html#card-2026-10-27-day-bookends)
- Focus timer (MD-4): `logic.startFocus`/`focusPhases`, focus rows in `myday_alarms`, +15 bonus XP. [story](../../patch_notes.html#card-2026-10-20-focus-timer)
- Good morning (MD-5): `ui.openMorning` (+ `dashDeck.ui._fillBrief`), opened by ☀️ I'm up (`ui.imUp`) or the Morning Brief button — never by the clock. [story](../../patch_notes.html#card-2026-10-20-good-morning)
- Evening review (MD-6): `ui.openEvening(opts)` — from 🌙 Going to bed (`opts.bed`: Skip review / Save & next → `ui.openGoodnight`) or as yesterday's catch-up on I'm up (`opts.catchUp`); Tomorrow/Drop/Skip; `journal` row `evening_review` → +10 Mind. [story](../../patch_notes.html#card-2026-10-20-evening-review)
- Day Bookends: `myday_settings.day_state` {day, up_at, bed_at}; one button `ui.dayButton` on the dashboard (`#dd-ld-daybtn`, filled from `dashDeck._refreshGlance`) and My Day Now/Next (`#mdx-daybtn`). `logic.startDay` = wake_override to press time + alarm done + `logic.slideOrder` blocks moved later by the lateness via `moveBlockAfter` (Undo); `logic.reviewPending` offers yesterday's review if Going to bed was never pressed; `logic.endDay` + `logic.suggestAlarm` (now + `health_settings.sleep_target_h`, capped by tomorrow's shift). Awake = up within 20h, no bed press (`logic.awake`). `missedItems` counts Morning only on a day started with I'm up. [story](../../patch_notes.html#card-2026-10-27-day-bookends)

- Drag timeline home (MDX) [story](../../patch_notes.html#card-2026-10-21-my-day-drag); Actions top the ▾ list (AC-1) [story](../../patch_notes.html#card-2026-10-21-actions).
