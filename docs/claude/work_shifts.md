# Work, shifts and rota — sub-file of the Schedule hub (`docs/claude/schedule.md`)
Modules `myDay` (work buttons), `workMode`, `shiftSync` (domain schedule). Facts only; stories in `patch_notes.html`.

- Work buttons (FL-7): `myDay.ui.workRow` on the Now/Next card from 30 min before a shift to 30 min after (`logic.workShift`); links in the private `work_links` table (kind clock_in/clock_out/break, `authenticated_all` only, read via `/api/data-write` action `read`), never in the repo; taps kept on the device (`mdx_work_taps`). [story](../../patch_notes.html#card-2026-10-27-work-clock-links)
- Work page (WR-8): `workMode` (src/schedule/workMode.js) shows `myDay.ui.workRow` plus tiles from the private `drink_specs` table (venue, section, name, kind cocktail/mocktail, ingredients[], price, glass, ice, method, garnish, measures jsonb, spec_source menu|sheet; `authenticated_all`, read via `kit.readPrivate`). 40 Nicco drinks are seeded from the menu. `ui.autoOpen` runs once per shift (localStorage `work_auto_<date>_<start>`, ±30 min, includes overnight shifts) on `rpgace:login`/`visibilitychange`. Entry points: leftNav Schedule, ⚡ Actions (`myday-act-work`, only on shift), Cooking shortcuts. [story](../../patch_notes.html#card-2026-11-03-work-mode)
- Shifts: `rpgace_shifts`; `rota-sync.yml` imports Fourth every Monday (`sync_status`); rota → `shiftSync.logic.fromRotaJson`. Push via edge fn `myday-push` + `push_digest()` (keys in `app_secrets`). Habit features: `routines.minimum`/`after_routine_id`, never-miss-twice, Sunday review (`journal` source `weekly_review`), `cutback_items`/`cutback_log`.
