## Briefs, journal, decisions
- `morningBrief` builds the Morning Brief from Supabase (`_autoRun()` waits for the login hook); `realmBrief` adds the realm pick and per-realm report periods; the daily Morning Brief Routine writes `journal` with the plain anon key.
- `oracleEntry` = Oracle "Save as entry" into the journal. [story](../../patch_notes.html#card-2026-10-16-oracle-save-entry)
- Realm Tasks (`realmTasks`, domain schedule): private `realm_tasks` (realm, type_key, title, kind repeat|once, rest_days 2, earns real|tick|xp, xp, status inbox|proposed|kept|dropped|done, dup_of, sources[]) + `realm_task_types` (13 realms × 5). A BEFORE INSERT trigger `realm_tasks_dedup` (pg_trgm) merges same/near-same titles (≥0.72) into one row keeping every source, flags 0.5–0.72 as `dup_of` in the inbox, and skips titles that are already an active Action. Never delete rows — set `dropped`.
- Feeds (database, automatic): `intel_reports_to_tasks` → `realm_tasks_from_report(uuid)` (every report's realm_sections quests), `journal_to_tasks` (I want to / I'll / I need to lines, max 3), `library_to_tasks` (book/link/article/course/recommendation saves). App: ➕ Task (`realmTasks.ui.openAdd`/`taskButton`) on Oracle replies (replaces ⚔️ Realm mission), idea cards, Bookworm insights; `pathways.logic.addQuest` and `questEngine.logic.addSuggested` keep a task via `realmTasks.logic.keepIdea`.
- ▶ Live now (`realmTasks.ui.openLive`, page `page-live`, card `liveNow`): opens on `myday:block-start` (fired by `myDay.logic.startFocus`); type chips ordered by the block's `chore_blocks.types` then least-recently worked; top 3 (`logic.rank`) + more; Done = `logic.doneInBlock` (adds a `src:'task'` item and ticks it through `myDay.logic.setBlockItem`, which pays +10, or the task's own XP for `earns:'xp'`). Explorer/Connector show Plans/People due. `realmOptions`, realm brief and Doing Now ideas read `realmTasks.logic.activities/activityMap`. Catalogue: `data/realm_tasks_catalogue.py`. [story](../../patch_notes.html#card-2026-10-27-realm-tasks)
