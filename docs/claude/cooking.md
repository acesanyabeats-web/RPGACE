## Cooking (`cookingOracle`)
- Tables: `recipes`, `ingredients`, `recipe_ingredients`, `ingredient_prices` (+ 4 cost/staleness/frequency views), `habits_config`, `planned_cooks`, `pantry_stock`, `shopping_lists`, `shopping_list_items`. All `anon_read_only`/`authenticated_all`.
- Generate via Oracle chat with a `RECIPE_JSON:` trailer, parsed from the raw reply with a fence-tolerant brace scan; short descriptions get a "Narrow it down" step (dish-type chips, optional ingredients, 5-idea suggest). Works from general Oracle chat too (rides `oracleAppGrounding`). [parse fix](../../patch_notes.html#card-2026-10-01-recipe-json-parse-fix)
- Review card: serving scaler, tagged step timeline with per-step timers; Save writes `recipes`/`recipe_ingredients` + a `journal` row. "Save to Journal" and "Add to Cook Session" are separate, deduplicated (`ensureRecipeSaved`).
- Revisions: the 🔮 overlay is recipe-aware (`registerContextProvider`); a typed critique returns `RECIPE_UPDATE_JSON:`, code computes the diff, Accept/Deny updates the card in place. Adding an ingredient offers "🔮 Update Method for this" via `oracleControl._sendFromOverlay`.
- Journey hub (Recipes → Plan → Shop → Cook → Stock + what's next), `ui._showMyRecipes`, ← back via `ui._wrapScreens`. Bought → `logic._addStock` at a chosen location. Every finish → `ui._offerStockUpdate` preview → `planned_cooks.stock_deducted` (undo once) → `shopping_lists.kind='topup'`. [story](../../patch_notes.html#card-2026-10-14-cooking-reorg)
- ☰/swipe side list on every Cooking screen: `RPGACE.sideList`, `ui._cookShortcuts`. [story](../../patch_notes.html#card-2026-10-21-cooking-side-list), app-wide [SL-0](../../patch_notes.html#card-2026-10-21-side-list-everywhere)
- Cook Mode: ▶ Start Cooking = one step per screen (scaled ingredients, equipment, done cue, timer, resume); last Done asks Actual/Preview/Not finished (`ui._askCookOutcome`); waiting steps' timers carry on in a bottom bar; 💬 Ask panel inside. New recipes get one-action steps; 8 old recipes have splits in `recipes.steps_proposed` awaiting Alex's Accept — one at a time (`ui._reviewProposedSteps`) or ✅ Accept all on My Recipes (`ui._acceptAllStepsBanner`, two-click, sequential, failures stay listed). [Cook Mode](../../patch_notes.html#card-2026-10-11-cook-mode) [timers](../../patch_notes.html#card-2026-10-15-cook-timers) [ask](../../patch_notes.html#card-2026-10-15-cook-ask) [outcome](../../patch_notes.html#card-2026-10-15-cook-outcome)
