# Realm pages and the menu — sub-file of the Chronicles hub (`docs/claude/chronicles.md`)
Module `realmPages` (domain chronicles) and the `leftNav` menu order. Realm tasks and Live now: `realm_tasks.md`. Facts only; stories in `patch_notes.html`.

- Realm pages (RP-1, Nov 4 2026, module `realmPages`, domain chronicles): `PAGES` maps a realm to an existing area page; `page:show` → `ui.attach(realm, opts)` puts `#rp-frame` on top (layout: the CP-1 line below). The tool section holds the area page's own nodes (Producer: `#bh-next`, `#bh-steps`); `ui.open(realm, {open})` scrolls to that section. `xpSeason.ui.openRealmHome(r)` opens the page. Take in / Log / Review open as sheets via `realmFrame.ui._openTakeIn/_openLog/_openReview`. [story](../../patch_notes.html#card-2026-11-04-rp1)
- Menu order (RP-2, Nov 4 2026): `leftNav.logic._items` = Dashboard, **Today** band (My Day, I'm up / Going to bed, Live now, I just did, Evening review, Calendar, Journal, Chronicles, Oracle, Ideas, Morning Brief, Review; open; no ⚡ Actions pop-up and no realm chip row since Nov 7), **Realms** band (`#ln-realm-list`, `realmPages.ui.menuItems`; open), then the area bands (Content & Video, Knowledge, Habits, Schedule & Journal = Work + Plans, Oversight). Money is listed once (Habits). `realmPages.logic.order(events, uses, now)`: last opened realm pinned, rest by xp_events count (30 days), then `ui_usage` opens, then `xpSeason.ORDER`; cached in localStorage `rpgace.rp.order`, refreshed by `loadOrder()` after the drawer builds; `logUse(realm)` (realm page attach + realm home open) writes `ui_usage` (private, `api/data-write.js` lists) and fires `realm:opened` → `leftNav.ui.redrawRealms`. `sideList.AREA_HEADINGS` maps myday/schedule/chronicles/oracle to Today. [story](../../patch_notes.html#card-2026-11-04-rp2)
- Every realm is a page (RP-3, Nov 5 2026): `realmPages.PAGES` - area pages wrapped (`tool.nodes '*'` moves the page's own content into the tool section): Creator=Posting, Hustler=Selling, Steward=Money (+ Wishlist extra), Scholar=Knowledge home; the rest share `#page-realm` (`ui._ensureGeneric`, `_current`): Chef (kitchen tools drawn in place, `cookingOracle.ui.drawTools`), Athlete (gym tools `gymPlan.ui.drawTools`, Health & body one of them; tool `alias: ['health']` keeps old links), Explorer (Plans), Connector (People tab), Homekeeper (`myDay.ui.renderChores` in place), Mind (Journal + decision log), Builder (Oversight card), Life (`workMode.ui.open({host})`). Only one `#rp-frame` exists at a time: `attach` calls `ui._detach` on others, which puts each page's own content back first. `xpSeason.ui.openRealmHome` now always opens the page. The menu's old area bands are `menuHidden` (not drawn; kept in `_items` for `sideList.areaGroup`); Review moved to Today. Live now Ask box saves cook chats (`realmTasks.ui._cookChatNote` → `cook_chats`, `cook_key live_<planned cook>`). [story](../../patch_notes.html#card-2026-11-05-rp3)
- Open on what you're doing (RP-4, Nov 5 2026): `realmPages.logic.nowPick(ctx)` (pure) picks the realm you're on - a running Doing now timer wins, then the block on now (`myDay.logic.dayBlocks`; `BLOCK_REALM` cooking→chef, gym→athlete, chores→homekeeper), then a work shift (→ life). `logic.now()` reads in-memory state; arriving at that realm's page from the menu opens Live (Life on a shift: Work) with "▶ On now: …". `logic.contextRealm()` = the realm page you're on, else what you're doing; `realmPicker._open` ticks it when a caller presets nothing (note "Ticked X from …"), and `myDay.ui.pickRealmBlock` lists it first with 📍. The app never jumps pages by itself. [story](../../patch_notes.html#card-2026-11-05-rp4)
- Switching cover (Nov 5 2026): `realmPages.ui._cover(realm)` puts a full-screen "Opening <realm>…" screen up on `page:show` before the first paint; `_uncover` takes it down once both the sections (`registry`) and the realm home (`realmFrame.ui.render` `opts.onReady`) are drawn, 4s at most. `realmFrame.ui._openPage(key)` resolves a page/tool key through `realmPages.logic.realmOfKey` first (cooking → Chef/Cooking, health → Athlete/Health, money → Steward) because RP-3 took the area bands out of the menu. [story](../../patch_notes.html#card-2026-11-05-switch-fixes)
