# Realm pages and the menu — sub-file of the Chronicles hub (`docs/claude/chronicles.md`)
Module `realmPages` (domain chronicles) and the `leftNav` menu order. Realm tasks and Live now: `realm_tasks.md`. Facts only; stories in `patch_notes.html`.

- Realm pages (RP-1, Nov 4 2026, module `realmPages`, domain chronicles): `PAGES` maps a realm to an existing area page; `page:show` → `ui.attach(realm, opts)` puts `#rp-frame` on top (xpSeason `stripFull` rank card + `realmFrame.ui.render(..., {noTiles:true})` target/what's next/ready from other realms) and folded `.rp-sec` sections from `logic.sections` (tool section first, then Tasks, Live, Take in, Log, Prompts, Weekly review). The tool section holds the area page's own nodes (Producer: `#bh-next`, `#bh-steps`). From the menu the tool section opens; `ui.open(realm, {open})` opens only that section; leaving and coming back refolds. `xpSeason.ui.openRealmHome(r)` opens the page when the realm has one (Producer = the Beats page, title 🎵 Producer); other realms keep their pop-up until RP-3. Take in / Log / Review draw inline via `realmFrame.ui._openTakeIn/_openLog/_openReview(..., host)`. [story](../../patch_notes.html#card-2026-11-04-rp1)
- Menu order (RP-2, Nov 4 2026): `leftNav.logic._items` = Dashboard, **Today** band (My Day, Live now, Calendar, Journal, Chronicles, Oracle, Ideas, Morning Brief; open), **Realms** band (`#ln-realm-list`, `realmPages.ui.menuItems`; open), then the area bands (Content & Video, Knowledge, Habits, Schedule & Journal = Work + Plans, Oversight). Money is listed once (Habits). `realmPages.logic.order(events, uses, now)`: last opened realm pinned, rest by xp_events count (30 days), then `ui_usage` opens, then `xpSeason.ORDER`; cached in localStorage `rpgace.rp.order`, refreshed by `loadOrder()` after the drawer builds; `logUse(realm)` (realm page attach + realm home open) writes `ui_usage` (private, `api/data-write.js` lists) and fires `realm:opened` → `leftNav.ui.redrawRealms`. `sideList.AREA_HEADINGS` maps myday/schedule/chronicles/oracle to Today. [story](../../patch_notes.html#card-2026-11-04-rp2)
- Every realm is a page (RP-3, Nov 5 2026): `realmPages.PAGES` - area pages wrapped (`tool.nodes '*'` moves the page's own content into the tool section): Creator=Posting, Hustler=Selling, Steward=Money (+ Wishlist extra), Scholar=Knowledge home; the rest share `#page-realm` (`ui._ensureGeneric`, `_current`): Chef (Cooking card), Athlete (gym drawn in place + Health extra), Explorer (Plans), Connector (People tab), Homekeeper (`myDay.ui.renderChores` in place), Mind (Journal + decision log), Builder (Oversight card), Life (`workMode.ui.open({host})`). Only one `#rp-frame` exists at a time: `attach` calls `ui._detach` on others, which puts each page's own content back first. `xpSeason.ui.openRealmHome` now always opens the page. The menu's old area bands are `menuHidden` (not drawn; kept in `_items` for `sideList.areaGroup`); Review moved to Today. Live now Ask box saves cook chats (`realmTasks.ui._cookChatNote` → `cook_chats`, `cook_key live_<planned cook>`). [story](../../patch_notes.html#card-2026-11-05-rp3)
- Do-first layout (RH, Nov 5 2026): `realmPages.ui.attach` = `ui._top` (slim `xpSeason.ui.strip` → `_sheetOf` rank card; `#rp-grow` → the stripFull hint lines) + `.rp-card #rp-do` (realmFrame home + `#rp-live`) + `#rp-sections.rp-grid` tiles (`logic.sections` = tool, extras incl. `act` tiles, tasks) + `#rp-foot` (`logic.FOOT`: log, takein, prompts, review → `ui._footOpen` sheets). `.rp-on` on the page hides its own `.xp-strip` and Money's Selling/Wishlist links. [story](../../patch_notes.html#card-2026-11-05-rh) 🔮 Ask Oracle (`_footOpen('prompts')`) opens `oracleControl._toggleOverlay` with the starters as `.rp-ask-chip`; context provider `realmPage` (realm, target, what's next, tiles). [story](../../patch_notes.html#card-2026-11-05-le)
- Open on what you're doing (RP-4, Nov 5 2026): `realmPages.logic.nowPick(ctx)` (pure) picks the realm you're on - a running Doing now timer wins, then the block on now (`myDay.logic.dayBlocks`; `BLOCK_REALM` cooking→chef, gym→athlete, chores→homekeeper), then a work shift (→ life). `logic.now()` reads in-memory state; arriving at that realm's page from the menu opens Live (Life on a shift: Work) with "▶ On now: …". `logic.contextRealm()` = the realm page you're on, else what you're doing; `realmPicker._open` ticks it when a caller presets nothing (note "Ticked X from …"), and `myDay.ui.pickRealmBlock` lists it first with 📍. The app never jumps pages by itself. [story](../../patch_notes.html#card-2026-11-05-rp4)
- Switching cover (Nov 5 2026): `realmPages.ui._cover(realm)` puts a full-screen "Opening <realm>…" screen up on `page:show` before the first paint; `_uncover` takes it down once both the sections (`registry`) and the realm home (`realmFrame.ui.render` `opts.onReady`) are drawn, 4s at most. `realmFrame.ui._openPage(key)` resolves a page/tool key through `realmPages.logic.realmOfKey` first (cooking → Chef/Cooking, health → Athlete/Health, money → Steward) because RP-3 took the area bands out of the menu. [story](../../patch_notes.html#card-2026-11-05-switch-fixes)
- No duplicate doors (Nov 5 2026): `#rp-rank .xp-slim-tgt` is hidden (the target shows once, in `#rp-do`); `logic.sections` gives a tool/extra with exactly one button (no `draw`/`nodes`) that button as its `act`, so the tile opens it in one tap; `dashDeck._popup` skips the rank strip when the active page's `#rp-frame` is the card's realm.
