# Realm Tasks & Generic Missions — every realm's to-dos (module `realmTasks`, domain schedule)
Cross-cutting: tasks belong to the 13 realms, not one area. Present tense, current facts only; stories in `patch_notes.html`.

- Realm Tasks (`realmTasks`): private `realm_tasks` (realm, type_key, title, kind repeat|once, earns real|tick|xp, xp, status inbox|proposed|kept|dropped|done|filed, dup_of, sources[], context_kind) + `realm_task_types` (13 × 5). A BEFORE INSERT trigger `realm_tasks_dedup` (pg_trgm) merges same/near-same titles (≥0.72) into one row keeping every source, flags 0.5–0.72 as `dup_of` in the inbox, and skips titles that are already an active Action. Never delete rows — set `dropped`.
- Feeds: DB triggers `intel_reports_to_tasks` → `realm_tasks_from_report(uuid)`, `journal_to_tasks` (I want to / I.ll / I need to), `library_to_tasks`. App: ➕ Task (`realmTasks.ui.openAdd`/`taskButton`) on Oracle replies, idea cards, Bookworm insights; `pathways.logic.addQuest` and `questEngine.logic.addSuggested` → `realmTasks.logic.keepIdea`.
- ▶ Live now (`realmTasks.ui.openLive`, page `page-live`, card `liveNow`): opens on `myday:block-start`; type chips by block `types` then least-recently worked; top 3 (`logic.rank`); Done = `logic.doneInBlock` → `myDay.logic.setBlockItem` (+10, or the task's XP for `earns:'xp'`). `realmOptions`, realm brief and Doing Now ideas read `logic.activities/activityMap`. Catalogue: `data/realm_tasks_catalogue.py`. [story](../../patch_notes.html#card-2026-10-27-realm-tasks)
- Generic Missions (GM, record `records/2026-10/generic_missions_paranoia_2026-10-27.txt`): a mission = realm task with `context_kind` (recipe/combo/reference/post/card); context cards in private `mission_contexts` (`realmTasks.logic.loadContexts`/`rankContexts`/`addContext`/`contextDone`). GM-3: `logic.fileInbox` (on opening 📥 New tasks; cheap model, `prompts/mission_file.md`, `sanitizeFiling`) files `MISSION_REALMS` inbox tasks as cards (task → status `filed`, `dup_of` mission); a misfit proposes an inbox mission.
- GM-5: in 📋 Plan block (`myDay.ui.planBlock`) ticking a mission opens `myDay.ui.pickContext` (`#mdp-ctx`: cards untried first, type your own → new card source typed, Decide later); the block item keeps `context_kind`/`context_id`/`context`, the Schedule line shows "(context)".
- GM-6: a recipe mission also gets ✨ Generate (`cookingOracle.logic._generate`, seeded with mission + card/typed text) → preview → Use: `_save` (My Recipes), a `generated` card with `recipe_id`, `cookingOracle.logic.planMissionCook` (scheduled `planned_cooks` on the block's own `agenda_id`, `_generateShoppingList`, `chore_blocks.planned_cook_id`); item keeps `recipe_id`.
