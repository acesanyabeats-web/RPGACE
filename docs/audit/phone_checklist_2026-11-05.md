# Phone checklist: buttons the audit can't test (AR-4, Nov 5 2026)

The UI audit runs with Oracle, Google and the analysers switched off, so these buttons always look dead there. Check each once on your phone. Tick it in Oversight → Smoke test when it works; if it doesn't, the error message (or nothing happening) is the thing to tell me.

| # | Where | Tap | What you should see |
|---|---|---|---|
| 1 | 💷 Steward page → 💷 Money → 🧰 My software | 🔎 Scan main Google account | "Scanning…", then software found in your Gmail receipts appears as new rows to Keep / Not needed. |
| 2 | Same screen | 🔎 Scan second Google account | Same as 1, for the second account. |
| 3 | 🧰 My software | 🎁 Find freebies: main Google account | Freebie emails listed as missions with a link to the email and to the claim page. |
| 4 | 📚 Scholar page → 📚 Knowledge → ＋ Take in | Paste a YouTube link → ⚡ Analyse | "Analysing…", then a write-up appears in your Library within a few minutes. |
| 5 | ☀️ My Day → Plan my day → 🗣 Plan with Oracle | Type "plan my day" → Send | Oracle asks what you need done, then shows a plan card you can Accept. |
| 6 | 🏠 Dashboard | The Ask box → Ask | An Oracle answer under the box. |
| 7 | ▶ Live now during a cooking block | 🔮 Ask Oracle → type a question → Ask | Reply under it; the chat is saved to the recipe (shows under the recipe's cook transcripts once that's built). |
| 8 | 📚 Knowledge → 📗 Study → 🧠 Explain it back | ▶ Start | Oracle asks you to explain a term; your answer gets feedback. |
