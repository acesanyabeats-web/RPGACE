Moved here from `interconnection_map.md` on Oct 28 2026 (CK-3/4, plan "Caps and Central Kit"); text unchanged. The root file keeps cross-domain sections and links here.

**☀️ My Day** (`myDay`, Oct 12 2026) — the one place daily/weekly routines live. Reads `routines` (Alex-picked rows; the module's `IDEAS` array is only a menu) and `quest_log` rows with `quest_kind='routine'`; writes both through `RPGACE.sb.secureWrite`. A tick writes a `quest_log` row, calls `addXP()` and, when timed, `questEngine.recordDuration('routine', id, …)` — so `questEngine._restoreBoardState` counts routine XP into the level with no second XP store. Plan my day reads shifts (`getShiftsForDate`) and today's `sched` entries, then writes accepted slots through `scheduleToCalendar()` with `source_type:'routine'`. Each routine's "Open" button calls `dashDeck._navOpenCard(key)`. Consumers: `dashDeck._refreshGlance` (Today: routines left), `cookingOracle`'s shopping list (`myDay.ui.appendShopping`, next-time-shopping routines), `acceptSuggestions()` and `addInstaQuest()` (one-off routines due today). The hardcoded `QUESTS` template is now empty. Timings (MD2-4): `myday_settings` (one row) + `activity_templates` feed `logic.shiftBefore/shiftAfter/travelBefore`, which `suggestSlots` and `logic.timeline` (Today's travel blocks + Prep/Leisure gaps) both use. The legacy `openSchedModal`/`confirmScheduleModal` call `myDay.ui.schedExtras`/`schedExtrasValues` for the template picker, category and place/journey, which `scheduleToCalendar()` stores on the `rpgace_agendas` row (`template_id`/`place`/`journey_mins`/`ready_mins`). Week planner (MD2-5): `routine_plans` (per-routine planned days) override a weekly routine's usual days and an N-a-week routine's count rule in `dueOn`/`isDueToday` for any week that has rows; `day_blocks` (time off / trip / event) plus shifts (`getShiftsForDate`) and `sched` feed `dayLoad`/`suggestDays` and the planner's day list; `dashDeck._refreshGlance` adds a Saturday "Plan next week" Due row. Chores (DT-3, Oct 14 2026): cadence `every_days` routines (area Chores) are due when `routines.every_days` days have passed since `logic.lastDone` — the later of `routines.last_done_before` and the newest completed `quest_log` tick, read from an all-time `quest_type=eq.every_days` query held in `myDay._choreDone` (the 70-day `_logs` window is too short for 90/180-day chores). `ui.renderChores` draws them as their own section instead of in the part-of-day groups; `ui.openChoreSetup` → `logic.addChores` bulk-inserts the starter list (`logic.spreadSeeds` staggers first due dates when no last-done is given). `xp_on_change` maps category chores → Homekeeper. Chore blocks (DT-4): `ui.openChoreBlock` → `logic.fillBlock` (due-by-date chores by `nextDue`, then next-due ones, greedy by `est_mins`, skipping chores in another planned block that day via `logic.blockedIds`) → `logic.saveChoreBlock` inserts `chore_blocks` (private-write via `/api/data-write`), calls `scheduleToCalendar()` (`source_type:'chore_block'`, `xp:0`) and stores the returned id as `chore_blocks.agenda_id`; `logic.cancelChoreBlock` sets status cancelled and deletes that `rpgace_agendas` row + the local `sched` entry. `ui.choreBlockCard` renders today's block inside `renderChores`, and its chores are removed from the main due list. Day templates (DT-1): `ui.openPlan(date)` (🗓 Plan my day) is the day template editor. `logic.dayKind` reads `getShiftsForDate` (closing = end ≤ start or ≥ 23:30 → late); `logic.learnedSource` picks the newest `day_templates` row with `source='locked'` of the same kind + weekday, else past `sched` entries (`logic.itemFromSched`, 56 days) of a same-kind day; `logic.buildDay` drops routines `dueOnDate` says aren't due (or are already handled today), refills chore blocks via `fillBlock`, and fits missing due routines with `suggestSlots`; `logic.clashes` marks overlaps with shift + `shiftBefore/shiftAfter`. `logic.lockDay` writes kept items through `scheduleToCalendar()` (skipping ones already on that day), `saveChoreBlock`, a `routine_plans` upsert for `plannable` routines, and a `day_templates` locked row; `logic.saveDayTemplate`/`removeDayTemplate` manage `source='saved'` rows. Night-before (DT-2): `dashDeck._refreshGlance` calls `myDay.logic.nightBeforeTarget(now)` (from 18:00 unless a shift is still running; 00:00–05:00 after a closing shift → today), then `nightBeforeStatus(target)` (a `day_templates` locked row or non-shift `sched` entries) and puts `nightBeforeRow` first in the Due list; its tap loads My Day and calls `ui.openPlan(target)`. Cooking + shopping blocks (DT-5/6): `chore_blocks` rows with `kind` cooking/shopping, an `items` checklist and `planned_cook_id`. `ui.pickRecipes` (recipes, length from `cookingOracle.logic._computeSessionSchedule`) and `ui.pickShopItems` (`logic.shopSources`: `cookingOracle.logic._computeIngredientUsage` for the day's cooking, `shopping_lists`/`shopping_list_items` of scheduled planned cooks + the newest list, `wishlist_items`, next-time-shopping routines, own text) build editor items `cooking_block`/`shopping_block`. `logic.lockDay` runs cooking blocks first: `saveCookingBlock` → `cookingOracle.logic._generateShoppingList` → `_acceptSchedule` (scheduled `planned_cooks` + Daily Schedule entry, `source_type:'planned_cook'`) → a `chore_blocks` row; then `saveShoppingBlock` matches 'cook' items to that list by ingredient and writes its own `scheduleToCalendar()` entry (`source_type:'shopping_block'`). `ui.lifeBlockCard` ticks via `logic.setBlockItem` (`shopping_list_items.bought`, `myDay.logic.tick`+`remove` for next-time routines, `shoppingWishlist.ui._showMarkBoughtConfirm` for Wishlist items) and calls `cookingOracle.logic._finishCook` when every dish is ticked; ▶ Start cooking calls `cookingOracle.logic._startCookNow`; `cancelChoreBlock` also sets a still-scheduled planned cook to `discarded`. `choreBlocksOn` only returns kind chores. Realm blocks (DT-7): `chore_blocks` kind `realm` + `realm`. `ui.pickRealmBlock` lists realms via `logic.realmChoices` (`xpSeason.logic.load`/`summary().week`, lowest first) and options via `logic.realmOptions` (`myDay.REALM_ACTIVITIES`, routines by `AREA_REALM`, `library_items` books not done and not from Bookworm via `tripPlans.logic.read`). `logic.saveRealmBlock` writes the row + a `scheduleToCalendar()` entry (`source_type:'realm_block'`). In `logic.setBlockItem`, a non-routine item with `earns:'tick'` inserts a `quest_log` row (`quest_kind:'block'`, `category` = realm) which `xp_on_change` pays as `block_tick` into that realm (untick deletes it); `earns:'real'` items only check off; routines go through `logic.tick`/`undo`. `ui.openActivity` routes Open buttons to dashDeck cards, `producerTools.ui.openOutreach`, `smoke_test.html` or Plan my day for tomorrow.

**🌌 XP Season Pass** (XP-1 + XP-2, Oct 13 2026) — the database owns XP. `xp_on_change()` (AFTER INSERT/UPDATE trigger on 15 tables) calls `xp_award(action, source_table, source_id, xp?, realm?, note?)`, which looks up `xp_rules`, applies the same-day cap (100/50/0) for `capped` actions and inserts one `xp_events` row (`unique(source_table, source_id, action)`, `season` 0 before 2027-01-01). `xp_on_delete()` marks same-week rows `pending_confirm`.
