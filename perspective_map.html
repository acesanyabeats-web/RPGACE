Methodology — how this page decides what counts as real

Only rows with status = 'active' or 'confirmed' render in the main sections above — these are real, evidence-gathered reports written under the actual /perspective procedure (a real code/git/Supabase read before a word is written). A separate, deliberately unverified scaffold (mainjs_function/onclick_feature/ decision scope rows, auto-generated by an earlier pass and never evidence-checked) is shown in its own collapsed, clearly-labeled section below — never mixed into the real set, because a truth-documentation page that presented stale scaffold content as equivalent to real evidence would undermine its own purpose.
