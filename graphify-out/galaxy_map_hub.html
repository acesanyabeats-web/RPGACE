🧭 How to read this map

Three words do most of the work here, and they are not interchangeable. 22 real pages, all of them one of the three.

📐 Level — a containment step
One thing physically inside the next. There are exactly 4:
🌌 L0 → 🏛️ L1 → 🌊 L2 → 🔽 Current (L3)
A galaxy contains rivers; a river contains modules; a module contains its own functions. That nesting is the whole test — if X does not literally sit inside the level above it, it is not a Level.
🌊 River — a one-home grouping
A real grouping of the codebase where every module belongs to exactly one. There are 17. That strict one-module-one-home property is what lets a River be a real containment step (L1) — and it is exactly why a Dimension can never be renumbered into one.
🌌 Dimension — a cross-cutting lens
The same modules and functions, viewed through one facet. Deliberately multi-membership: one module can appear in several at once. There are 15: Decision Matrix, Dimensions Matrix, Decisions — Human Gates, Branch Ledger, Supabase, Externals, Load Dimension, Skills, Alex’s Decision Path, Orchestrator CC, OpenMontage CC, Oversight Sync, Loops, Local Analysis Pipeline, Generator Toolchain. Equal standing with Rivers, different shape — a Dimension answers "what does this touch", a River answers "where does this live".
